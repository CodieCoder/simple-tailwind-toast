# Security Policy

## Supported Versions

Security fixes target the latest published major version.

| Version | Supported |
| ------- | --------- |
| 2.x     | Yes       |
| 1.x     | No        |

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Report security concerns through GitHub's private vulnerability reporting if it is enabled for this repository. If it is not enabled, contact the maintainer through the repository owner profile and include:

- A clear description of the issue.
- Steps to reproduce or a minimal proof of concept.
- The affected package version.
- Any known workarounds.

The maintainer will acknowledge valid reports as soon as possible and coordinate a fix before public disclosure.

## Scope

This package is a client-side React notification library. Reports are most useful when they involve package integrity, unsafe rendering behavior, dependency risk, build output, or documentation that could lead users into insecure usage.
