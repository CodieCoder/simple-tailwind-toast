# Code of Conduct

This project should be a welcoming place for practical, respectful collaboration.

## Expected Behavior

- Be kind and direct.
- Assume good intent, but accept corrections gracefully.
- Keep criticism focused on the work, not the person.
- Respect maintainers' time by keeping issues and pull requests clear and actionable.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Discriminatory language or behavior.
- Repeated off-topic comments after maintainers ask to stop.
- Publishing private information without permission.

## Enforcement

Maintainers may edit, hide, or remove comments, close issues, reject pull requests, or block participants who violate this code of conduct.

If you need to report a concern, contact the maintainer through the repository owner profile. Include links, screenshots, or context when available.
