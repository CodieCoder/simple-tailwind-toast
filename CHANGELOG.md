# Changelog

All notable changes to this project will be documented here.

This project follows semantic versioning.

## Unreleased

- Added public repository contribution, security, code of conduct, and pull request documentation.

## 2.0.0

- Reworked the package around a providerless `toast` API and `<Toaster />` component.
- Replaced the old provider and hook API.
- Updated package entrypoints to ESM and CommonJS builds.
- Removed bundled CSS output and CSS injection.
- Removed runtime dependencies and kept React as a peer dependency.
- Added SSR import coverage and renderer/store tests.
- Updated README usage, Tailwind setup, customization, and bundle notes.
